# 生物信息学在线分析平台

纯前端、**零外部依赖、可完全离线**的生物信息学常用分析工具集（12 个模块）。所有计算都在浏览器中完成，数据仅在本地处理。

## 使用方式

**双击 `index.html` 即可**（无需安装、无需服务器、无需联网）。
将整个文件夹复制到 U 盘或任意电脑上即可直接运行。

## 功能与输入格式

每个模块页面顶部都会显示**输入数据格式示例**，并提供「下载模板」「加载示例数据」「复制示例」按钮，也支持直接从 Excel 粘贴。

| 模块 | 输入格式 | 输出 |
|---|---|---|
| **韦恩图 / Venn** | ① 长表 `Set ⇥ Element`；② 宽表 0/1 矩阵；③ 分列（每列一组）；④ 多文件（每个文件 = 一个集合） | 2–4 集合韦恩图、各集合大小、交集明细表（可逐区域导出基因）、两两交集矩阵 |
| **UpSet 图** | 同上 | 交集体量柱状图 + 成员点阵矩阵，支持按大小/集合数排序、Top-N、最小交集过滤 |
| **富集分析 / ORA** | ① 单列基因列表；② 多列表 `列表名: 基因1, 基因2…`。基因集来源：本地 GMT 上传 / 内置示例库 / Enrichr 在线库 | 超几何检验 + BH/Bonferroni/Holm 校正，气泡图、条形图、多列表对比点图、结果表 |
| **相关性分析** | ① 宽表（样本 × 变量）；② 长表（样本/变量/数值） | Pearson / Spearman / Kendall 系数、P 值、FDR；聚类热图、散点回归图、相关网络、配对结果表 |
| **PCA** | 样本 × 特征矩阵（可选分组列） | 碎石图、PC1–PC2 得分图（分组 95% 置信椭圆、载荷箭头）、载荷表 |
| **火山图** | `gene ⇥ log2FC ⇥ pvalue(/padj)` | 火山图（可调阈值、Top 基因标注）、差异基因表 |
| **聚类热图** | 基因 × 样本矩阵（可选样本分组注释） | Z-score 标准化、行列层次聚类 + 树状图、分组色条、导出聚类后矩阵 |
| **差异表达分析** | 表达矩阵（基因 × 样本）+ 样本分组注释（单独填写） | 两组：Welch t / Wilcoxon 秩和；多组：单因素 ANOVA / Kruskal-Wallis。log2FC、统计量、P 值、FDR、分组箱线图（含显著性标记）、结果表 |
| **生存分析** | 逐行样本：随访时间、事件状态、分组（列名自动识别；无分组时可用连续变量按中位数自动二分） | Kaplan-Meier 阶梯曲线（95% CI、删失标记）、log-rank 检验、中位生存期汇总、风险表 |
| **ROC 曲线与 AUC** | 真实标签列 + 一个或多个打分列 | 多标记物 ROC 曲线、AUC（梯形积分）、Hanley-McNeil 95% CI、Youden 最佳截断、灵敏度/特异度/PPV/NPV/准确率/F1、混淆矩阵、阈值明细 |
| **序列与蛋白工具** | FASTA 或纯序列文本（自动识别核酸 / 蛋白） | 核酸：反向互补、GC 含量、碱基组成图、六框翻译、ORF 查找、密码子使用表、Tm 估算；蛋白：分子量、等电点 pI、氨基酸组成、GRAVY、芳香性、疏水性滑窗 |
| **去除重复 / 唯一化** | 任意表格（基因列表或带注释的多列表） | 四种模式：去除完全重复行 / 按关键列去重（保留首次或最后出现）/ 按关键列聚合（均值、最大、最小、求和、计数等）/ 提取唯一值列表 |

所有图形均可导出 **SVG**（矢量，投稿排版用）与 **PNG**（2× 分辨率），所有表格可导出 **TSV / CSV**。

## 中英文界面

左下角「界面语言」可在**中文 / English** 之间直接切换，整个页面（导航、标题、按钮、参数、说明、结果卡片）与图形内文字（坐标轴、图例、标注、提示）**同步切换**；
切换后输入的数据保留，并自动按新语言重算一次。选择记忆在浏览器本地存储。来自数据的文字（基因名、样本名、分组名、通路名）不会被翻译。

## 算法口径

- **富集分析**：过表征分析（ORA），超几何检验上尾 `P(X ≥ k)`，等价于 Fisher 精确检验单侧；
  富集倍数 = (k/n)/(K/N)；Rich factor = k/K；Gene ratio = k/n；默认 Benjamini–Hochberg 校正。
- **相关性**：Pearson / Spearman 用 t 近似（df = n−2）；Kendall tau-b 含并列校正、正态近似 P 值；缺失值成对删失。
- **PCA**：中心化（可选 z-score 标准化）后做协方差矩阵特征分解（Jacobi 旋转）。
- **层次聚类**：Lance–Williams 更新，支持 single / complete / average(UPGMA) / Ward.D2；
  距离支持欧氏、曼哈顿、最大距离、余弦、1 − 相关系数。
- **差异表达**：两组用 Welch t（Welch–Satterthwaite 自由度）或 Wilcoxon 秩和（正态近似 + 并列与连续性校正）；
  多组用单因素 ANOVA（F 上尾）或 Kruskal-Wallis（H 统计量，χ² 近似）；log2FC 在 log 尺度上直接相减，原始强度先取 log2。
- **生存分析**：Kaplan-Meier 乘积极限估计；置信区间用 Greenwood 方差线性近似（±1.96·SE）；
  log-rank 检验为 Mantel–Haenszel 形式 `χ² = (O−E)′V⁻¹(O−E)`，与 R `survdiff` 口径一致。
- **ROC / AUC**：AUC = 梯形积分，等价于 Mann-Whitney U / (n₁n₂)；95% CI 用 Hanley-McNeil 近似；
  最佳截断取 Youden 指数（灵敏度 + 特异度 − 1）最大处；判别方向可自动判断（按两组均值）或手动指定。
- **序列**：翻译用标准/线粒体密码子表；Tm ≤ 14 nt 用 Wallace 规则，> 14 nt 用 GC 近似公式（粗略估计）；
  蛋白分子量 = 残基平均质量之和 + 18.0153 Da；pI 按 pKa 表对 pH 0–14 二分搜索净电荷零点。

统计内核（t / F / χ² 分布、Welch t、Wilcoxon、ANOVA、Kruskal-Wallis、Kaplan-Meier、log-rank 等）
均已用 R 参考值逐项校验（详见 `selftest.html`）。

## 注意事项

- **内置示例基因集仅供功能演示**（16 条小型示例通路），正式分析请上传 MSigDB / GO / KEGG 官方 GMT 文件，
  或使用「在线获取 Enrichr 基因集库」（需联网，首次获取后缓存到浏览器）。
- 富集分析的**背景基因集**默认取基因集库的全部基因；若实验只检测了部分基因（靶向 panel / 芯片），请填写真实背景。
- 大数据量建议：UpSet 集合数 ≤ 8；热图行数 ≤ 500；相关性变量数 ≤ 60；单文件 < 20 MB。
- 生存分析要求**删失与事件相互独立**；中位生存期只在随访期内生存概率降到 50% 以下时才有定义。
- ROC 的 Youden 最佳截断仅作参考，实际阈值应结合临床或实验成本权衡；多标记物比较 AUC 时应考虑 DeLong 检验。
- Tm 估算为粗略值，精确定量请使用最近邻热力学模型并考虑盐浓度与 Mg²⁺。
- 统计显著 ≠ 生物学显著，请结合效应量与实验设计综合判断。
